🧠 클로드 또는 챗GPT 유료 구독 하나

봇을 돌리는 두뇌예요. 둘 중 아무거나 하나만 있으면 됩니다.

내 구독오픈클로에서 부르는 이름
클로드 (Claude Pro 등)Claude CLI

💡 최소 요금제(월 $20)면 충분해요. 둘 다 있을 필요 없어요.

💡 그 구독을 결제한 계정의 아이디·비밀번호를 알고 오셔야 해요. 나중에 로그인할 때 써요.

API 키? 그런 거 필요 없어요! 🎉
이미 내고 있는 구독을 그대로 재사용해요. 브라우저에서 로그인카카오 로그인, 구글 로그인 해보셨죠? 그거예요! 브라우저에서 "허용" 버튼 한 번 누르면 끝. 비밀번호 따로 만들 필요 없어요! 한 번만 하면 끝이에요.

컴퓨터에 미리 깔 건요?

공통으로 파세오(작업 창)를 하나 깔고 시작해요. VS Code·Cursor를 이미 쓰신다면 그걸 쓰시면 돼요.

Chapter 1-1

준비물 설치하기 🛠

내 구독에 따라 준비물이 조금 달라요. 탭을 눌러 내 컴퓨터에 맞는 쪽을 보세요.

0️⃣ 먼저 — 작업할 창부터 편하게 (파세오)

이미 VS Code나 Cursor를 쓰고 계신가요?
그럼 이 단계는 건너뛰세요. 그걸 그대로 쓰시면 돼요.

둘 다 안 쓰신다면 파세오(Paseo)를 깔아요. 왜냐면요:

  • 기본 터미널은 화면이 불편해요. 글자만 빽빽하고 되돌리기도 어렵죠.
  • 봇의 성격 파일(.md)을 바로 열어 고칠 수 있어요. 오늘 뒤에서 봇 성격을 적을 건데, 그때 편해요.

paseo.sh/download 접속 → Windows 설치 파일(.exe) 내려받아 실행

💡 대부분 Intel/x64를 고르면 돼요. 최근 산 ARM 노트북이면 ARM64.

paseo.sh/download 접속 → macOS 버전 내려받아 실행

💡 Apple Silicon(M1·M2·M3·M4)과 Intel 중에 골라요. 잘 모르겠으면 왼쪽 위 🍎 → "이 Mac에 관하여"에서 확인!

macOS 12 이상이 필요해요.

깔고 나면 파세오를 열고, 그 안의 터미널에서 아래 단계를 진행하면 돼요. (기본 터미널로 하셔도 결과는 똑같아요!)

1 파워셸 열기

키보드에서 Windows 키 → "PowerShell" 검색 → 그냥 클릭

💡 파워셸은 윈도우에 원래 들어있어요. 따로 설치할 필요 없어요.

💡 "관리자로 실행"을 굳이 고르지 마세요. 회사 노트북이라 관리자 권한이 없어도 진행돼요.

💡 파워셸에서 붙여넣기는 마우스 오른쪽 클릭이에요.

✅ 윈도우는 따로 깔 프로그램이 없어요!

Node.js는 다음 장 설치 명령이 알아서 챙겨 깔아줘요.
(winget · Chocolatey · Scoop 순서로 시도하고, 셋 다 없으면 통째로 받아서 넣어줘요)
2 확인만 한 번 (30초)

깔 건 없지만, 이미 있는지만 보고 가면 나중에 덜 헤매요.

파워셸 node --version

v22.22.3 이상 / v24.15 이상 / v25.9 이상 중 하나가 나오면 → 이미 있는 거예요. 좋아요!
용어가 cmdlet 이름으로... 이 나와도 → 정상이에요. 다음 장에서 알아서 깔려요.

⚠️ 혹시 다음 장에서 Node 설치가 실패한다면

회사 노트북의 방화벽이 내려받기를 막는 경우가 있어요.

→ nodejs.org 에서 직접 받아 설치하면 돼요. 손 들어주시면 같이 봐드릴게요.

3 내 구독에 맞는 준비 (둘 중 하나만!)

🅐 클로드(Claude) 구독이라면 — Claude Code 설치

오픈클로가 클로드에 직접 로그인하는 게 아니라, 이미 로그인된 Claude Code를 빌려 쓰는 방식이에요. 빌릴 게 있어야 하니 먼저 깔아둬요.

이미 있는지 먼저 확인:

파워셸 claude --version

숫자가 나오면 → 로그인만 하면 돼요. 못 찾는다고 나오면 → 아래 설치.

파워셸 irm https://claude.ai/install.ps1 | iex

⚠️ 설치 직후 claude 를 못 찾는다고 나오면 파워셸을 닫고 새로 열어서 다시 해보세요. 흔한 일이에요.

새 창에서 로그인:

파워셸 claude

브라우저가 열리면 평소 쓰는 클로드 계정으로 로그인 → 끝나면 /exit 로 나오기.

⚠️ 로그인 계정과 구독을 결제한 계정이 같아야 해요.

🅑 챗GPT(ChatGPT) 구독이라면 — Codex CLI 설치

클로드와 같은 이유예요. 미리 로그인해두면 오픈클로가 그걸 찾아서 그대로 씁니다.

⚠️ 윈도우는 순서가 하나 달라요!
이 설치엔 npm 이 필요한데, 그건 Chapter 2(오픈클로 설치) 때 같이 깔려요.
→ Chapter 2를 먼저 하고, 그다음 여기로 돌아와서 아래를 진행해주세요.

이미 있는지 먼저 확인:

파워셸 codex --version

숫자가 나오면 → 로그인만. 못 찾는다고 나오면 → 아래 설치.

파워셸 npm install -g @openai/codex

⚠️ @openai/ 를 꼭 붙여주세요. 그냥 codex 는 전혀 다른 옛날 패키지예요.

깔고 나서 로그인:

파워셸 codex

메뉴에서 "Sign in with ChatGPT" 를 고르면 브라우저가 열려요.

⚠️ 설치 직후 codex 를 못 찾으면 파워셸을 닫고 새로 열어서 다시 해보세요.

여기까지 했으면 Chapter 2 (오픈클로 설치)로 가세요!
1 터미널 열기
Cmd + Space → "터미널" 또는 "Terminal" 입력 → Enter
2 Homebrew맥에서 프로그램을 쉽게 깔아주는 도우미예요. 앱스토어처럼 "이거 깔아줘!" 하면 알아서 깔아줘요. 근데 마우스 대신 글자로! 있는지 확인

먼저 이미 깔려 있는지 봐요. 아래를 복사해서 붙여넣고 Enter:

터미널 brew --version

Homebrew 4.x.x 처럼 숫자가 나오면 이미 있는 거예요 → 3번은 건너뛰고 Chapter 2로!

command not found 가 나오면 → 아래 3번으로.

3 Homebrew 설치 (없는 경우만)
터미널 /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

비밀번호를 물어보면 맥 로그인 비밀번호를 입력하세요. (화면에 안 보이는 게 정상!)
5~10분 정도 걸려요. 진행이 멈춘 것처럼 보여도 기다려주세요.

설치가 끝나면 화면 맨 아래를 봐주세요.
Run these commands in your terminal... 하고 명령어 두 줄이 나와요.
그 두 줄을 그대로 복사해서 실행해야 brew 명령이 계속 먹어요. 안 하면 터미널을 새로 열 때마다 "brew를 찾을 수 없다"고 나와요.
4 잘 깔렸는지 확인
터미널 brew --version
Homebrew 4.x.x ← 숫자가 나오면 성공! 🎉
⚠️ 설치가 안 되고 관리자 권한 얘기가 나오면

Homebrew는 설치할 때 관리자 계정이 필요해요. 회사에서 지급받은 맥북은 관리자가 아닌 경우가 있어요.

→ 억지로 우회하지 마시고 손 들어주세요. 함께 방법을 찾을게요.

5 Node.js자동차에 엔진이 필요하듯, 오픈클로가 돌아가는 데 필요한 프로그램이에요. 한 번만 깔면 끝이고 이후엔 신경 안 써도 돼요. 설치

먼저 이미 있는지 봐요:

터미널 node --version

v22.22.3 이상 / v24.15 이상 / v25.9 이상 중 하나가 나오면 → 이미 있는 거예요. Chapter 2로!
command not found 가 나오거나 숫자가 더 낮으면 → 아래를 실행하세요.

터미널 brew install node

몇 분 걸려요. 끝나면 node --version 을 다시 쳐서 숫자를 확인해주세요.

⚠️ 설치했는데도 낮은 버전이 계속 나온다면

예전에 다른 방법으로 Node를 깔아둔 경우예요(nvm 등). 새로 깐 게 아니라 옛날 것이 계속 잡히는 거예요.

→ 화면에 export PATH=... 같은 안내가 나왔으면 그대로 따라 하고 터미널을 새로 여세요. 헷갈리면 손 들어주세요 — 여기서 혼자 오래 붙잡지 마세요.

💡 이 단계를 건너뛰어도 다음 장 설치 명령이 알아서 깔아주긴 해요. 다만 이미 옛날 Node가 있으면 거기서 에러가 나며 멈춰요. 그래서 여기서 미리 확인하고 가는 거예요.

봇을 붙이려면 앱 설치 권한이 필요한데, 회사 슬랙은 대부분 관리자 승인이 필요해서 오늘 안에 안 끝나요.

→ slack.com/get-started 에서 개인 워크스페이스를 무료로 하나 만들어주세요. 3분이면 돼요. 회사 슬랙은 오늘 익힌 다음에 붙이면 됩니다.

1 슬랙 앱 만들기 — 매니페스트 한 덩이로

api.slack.com/apps 접속 → Create New App → From an app manifest → 내 워크스페이스 선택

📝 붙여넣기 전에 두 군데만 바꿔주세요
"name" → 한글 이름 (예: 뽀야, 구름이)
"display_name" → 영문 아이디 (예: bboya, gureum)
나머지는 그대로 두세요. 봇이 할 수 있는 일의 범위라, 지우면 나중에 조용히 안 되는 기능이 생겨요.
(오픈클로 공식 권장 설정이에요 — 1:1 DM·채널·그룹 DM·파일·이모지 반응까지 다 됩니다.)

Next → 미리보기 확인 → Create 클릭. 이러면 권한·이벤트·Socket Mode가 한 번에 다 켜진 상태로 만들어져요.

2 슬랙에서 부를 이름 한글로 바꾸기

매니페스트엔 영문 아이디를 넣었으니, 슬랙에서 @뽀야 처럼 한글로 부르려면 한 번 더 손봐야 해요.

왼쪽 메뉴 App Home → Your App's Presence in Slack → Edit → Display Name (Bot Name) 을 한글로 → Save

3 열쇠 ① 앱 토큰 xapp-

Socket Mode는 켜졌지만 앱 토큰은 자동으로 안 만들어져요. 직접 발급해요.

왼쪽 메뉴 Basic Information → 아래로 스크롤 → App-Level Tokens → Generate Token and Scopes

이름은 아무거나(bboya) → Add permission by Scope 에서 connections:write 하나만 선택 → Generate

💡 드롭다운에 scope가 3개 뜨는데 connections:write 하나면 충분해요. 나머지 둘은 여러 워크스페이스에 배포하는 앱용이라 우리한텐 불필요해요.
⚠️ 이 토큰은 창을 닫으면 다시 못 봐요

→ 나오자마자 메모장에 붙여넣어 두세요. xapp- 으로 시작해요.

4 열쇠 ② 봇 토큰 xoxb-

왼쪽 메뉴 Install App → Install to Workspace → 권한 허용

Bot User OAuth Token 이 나와요 → 이것도 메모장에! xoxb- 로 시작해요.

🔑 이제 토큰이 두 개 모였어요
xapp- 앱 토큰 (3단계)  /  xoxb- 봇 토큰 (4단계)
⚠️ 둘을 바꿔 넣는 게 제일 흔한 사고예요. 에러도 안 뜨고 그냥 조용히 대답을 안 해요. 앞 글자로 구분하세요.
⚠️ 토큰은 비밀번호와 같아요. 채팅방이나 카톡에 붙여넣지 마세요.
5 오픈클로에 연결

대화 창에서 이렇게 말해요:

대화 창에 입력 슬랙 연결해줘

그다음 물어보는 대로 토큰 두 개를 알려주면 연결돼요. 메모장에 복사해둔 xoxb- 와 xapp- 을 붙여넣으면 됩니다.

💡 --account 같은 걸 물으면 이 슬랙을 부르는 별명을 정해주세요. 영문 소문자로 짧게 (예: mycompany, test). 나중에 회사 슬랙을 하나 더 붙일 때 이 이름으로 구분해요.

⚠️ "호스트 마법사가 안 뜨네요" 라고 나와도 정상이에요

원래는 토큰을 가려서 받는 전용 창이 떠야 하는데, 터미널 대화 창엔 그 기능이 없어요. 그래서 대신 말로 물어봐요. 고장 아니에요.

→ 다만 이 경우 토큰이 화면에 그대로 보여요. 화면 공유 중이거나 옆에 사람이 있으면 아래 메뉴 방식을 쓰세요.

🔀 대화가 헷갈리면 — 메뉴에서 골라 넣기
새 창을 하나 열어서 아래를 실행하면 메뉴가 뜨고 토큰도 가려서 받아요.
새 창 (파워셸/터미널) openclaw configure --section channels
목록에서 Slack 을 고르고, 물어보는 대로 토큰을 붙여넣으면 돼요. 입력할 때 화면에 안 보이는 게 정상이에요 — 가려서 받는 거라서요.
설정이 바로 반영돼요. 게이트웨이를 다시 켤 필요 없어요!
6 슬랙에서 첫 인사

슬랙 왼쪽 사이드바 맨 아래 앱 영역에서 내 봇을 찾아 눌러요.

💡 "앱"이 안 보이면 — 그 영역의 점 3개(⋯) → 필터 → "모두" 선택

DM 창에 안녕? 하고 보내보세요.

⚠️ 대답이 없다면 — 승인이 남았을 수 있어요

텔레그램 때와 같아요. 새 창에서 확인해보세요:

openclaw pairing list slack → 코드가 보이면 openclaw pairing approve slack <코드>

7 채널에도 불러오기

DM 말고 채널에서 쓰려면 초대를 해야 해요. 사람이랑 똑같아요.

슬랙 채널에 입력 /invite @내봇이름

그다음 @내봇 안녕 처럼 이름을 불러서 말 걸어요. 채널에서는 불러야 대답해요 — 안 그러면 사람들 대화에 계속 끼어들거든요.

✅ 슬랙에서 답이 오면 오늘 목표 달성이에요! 🎉
이제 저는 팀원들 사이에 앉아 있어요 💬
채널에서 이름 불러주시면 바로 갈게요 🐾

1 게이트웨이 상태 확인

파워셸(윈도우) / 터미널(맥) openclaw gateway status

수동 실행 시 주의! 터미널을 닫으면 게이트웨이도 꺼져요.

3 텔레그램에서 첫 메시지 보내기!
⚠️ 먼저 알아두세요 — 첫 메시지엔 바로 대답 안 해요!
고장이 아니에요. 봇 아이디만 알면 아무나 말을 걸 수 있어서, 오픈클로는 처음 말 건 사람에게 번호표(코드)를 주고 주인이 승인해야 대화를 열어줘요. 4번에서 승인할 거예요.
  1. 텔레그램 검색창에 @내봇유저네임 검색 (예: @ppoya_test_bot)
  2. /start 버튼을 누르거나 직접 입력
  3. 아무 말이나 보내보세요! 예: "안녕 뽀야!"
4 승인하기 (여기가 마지막 관문!)

컴퓨터로 돌아와서, 기다리고 있는 요청을 봐요:

파워셸(윈도우) / 터미널(맥) openclaw pairing list telegram

화면에 코드가 하나 보일 거예요. 그 코드로 승인해요 — <코드> 자리에 화면에 나온 값을 넣으세요(꺾쇠는 빼고):

파워셸(윈도우) / 터미널(맥) openclaw pairing approve telegram <코드>
⚠️ 목록이 비어 있다면

코드는 1시간이 지나면 사라져요. 또는 아직 메시지가 도착하지 않았을 수도 있어요.

→ 텔레그램에서 봇에게 말을 한 번 더 걸고 openclaw pairing list telegram 을 다시 쳐보세요. 설정을 뜯어보기 전에 이것부터!
