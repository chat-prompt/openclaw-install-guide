시작하기 전에 딱 두 가지만 깔면 돼요

🪟 윈도우 사용자는 여길 먼저 봐주세요!

두 가지 길이 있어요. 하나만 고르면 돼요.

🅐 WSL2 (권장) — 윈도우 안에 리눅스를 깔아서, 그 다음부터는 맥과 완전히 동일하게 진행해요.

파워셸 (관리자) wsl --install -d Ubuntu

🅑 파워셸만 쓰기 — WSL이 안 되거나 부담스러우면 윈도우 그대로 설치해도 돼요.

파워셸 (관리자 권한 불필요) iwr -useb https://openclaw.ai/install.ps1 | iex

🅐는 다음 슬라이드, 🅑는 그 다음 슬라이드에서 상세 안내!

⚙️ 윈도우·맥 둘 다

Node.js자동차한테 엔진이 필요하듯, 오픈클로한테 Node.js가 필요해요. 한 번만 깔면 끝이고, 이후엔 신경 안 써도 돼요!

오픈클로의 엔진이에요.
이게 있어야 오픈클로가 돌아가요. 한 번만 깔면 끝!

✅ Node.js는 여전히 필수예요. 다만 설치 스크립트가 없으면 알아서 깔아주니, 직접 신경 안 쓰셔도 돼요. (24 LTS 권장 · 23은 지원 안 함)

❌ Git은 필요 없어요. 기본 설치는 npm 방식이라 Git 없이 돌아가요.

API 키? 그런 거 필요 없어요! 🎉
오픈클로는 OAuth카카오 로그인, 구글 로그인 해보셨죠? 그거예요! 브라우저에서 "허용" 버튼 한 번 누르면 끝. 비밀번호 따로 만들 필요 없어요! 로그인을 지원해서, 나중에 브라우저에서 로그인만 하면 돼요.
맥 유저는 Node.js만 챙기면 끝!

모르는 용어가 나오면 밑줄 친 단어에 마우스를 올려보세요.

Chapter 1-1 · 윈도우만

🪟 윈도우 사용자는 여기부터!

윈도우에서 오픈클로 설치, 생각보다 훨씬 간단해요.
wsl --install -d Ubuntu 명령어 한 줄로 리눅스 환경이 세팅되고,
그 다음은 맥과 완전히 동일합니다!

🍎 맥 사용자는 이 페이지 스킵! → "다음" 버튼 누르세요

WSL이 안 깔리거나 부담스러우면? 다음 슬라이드(1-1 대안)의 파워셸 방식으로 하셔도 돼요. 둘 중 하나만 하면 됩니다.
1 파워셸을 관리자 권한으로 실행

키보드에서 Windows 키 → "PowerShell" 검색 → "관리자로 실행" 클릭

2 WSL + Ubuntu 설치 (명령어 한 줄!)
파워셸 (관리자) wsl --install -d Ubuntu

WSL과 Ubuntu가 함께 설치돼요. 끝나면 컴퓨터를 재시작하세요.

3 재시작 후 Ubuntu 열기

시작 메뉴에서 "Ubuntu" 검색 → 클릭하면 터미널이 열려요.

처음 실행하면 사용자 이름/비밀번호를 만들라고 해요:

  • 사용자 이름: 영어 소문자 (예: myname)
  • 비밀번호: 아무거나 (입력할 때 화면에 안 보이는 게 정상!)
4 오픈클로 설치 (이것도 한 줄!)
Ubuntu 터미널 curl -fsSL https://openclaw.ai/install.sh | bash

Node.js가 없으면 자동으로 설치해줘요. 약 7분 정도 걸려요.

✅ 이게 끝이에요!
WSL 설치 + 오픈클로 설치 = 명령어 딱 2줄.
설치가 끝나면 자동으로 온보딩이 시작돼요 → 이 가이드의 Chapter 3 (온보딩)부터 이어서!
🔧 혹시 안 되나요? (클릭하면 열려요)
❌ "가상 머신 플랫폼" 오류 / WslRegisterDistribution failed

BIOS에서 가상화(VT-x / AMD-V)가 꺼져있을 때 나와요.

→ 컴퓨터 재부팅 → BIOS 진입(보통 F2/DEL) → Virtualization Technology를 Enabled로 변경 → 저장 후 재부팅

❌ wsl --install 자체가 안 먹어요 (명령어를 찾을 수 없음)

Windows 10 버전 2004 미만이면 WSL 명령어 자체가 없어요.

→ 설정 → 시스템 → 정보에서 버전 확인! → Windows Update로 최신 버전 업데이트 먼저!

→ 그래도 안 되면 코난쌤의 WSL 상세 가이드 또는 리도님의 윈도우 가이드를 따라해보세요.

❌ Microsoft Store 관련 오류 (0x80070422 등)

회사/학교 PC에서 Microsoft Store가 정책으로 막혀있을 때 발생해요.

→ 파워셸(관리자)에서 수동 설치:
wsl --install -d Ubuntu --web-download
Store를 거치지 않고 웹에서 직접 다운로드해요.

❌ Ubuntu가 시작 메뉴에 안 보여요

→ 컴퓨터를 재시작했는지 확인! 재시작 후에도 안 보이면 Microsoft Store에서 "Ubuntu"를 검색해서 직접 설치하세요.

❌ curl 명령어가 안 먹어요

→ 파워셸이 아니라 Ubuntu 터미널에서 실행해야 해요! 시작 메뉴에서 "Ubuntu"를 열어주세요.

위 방법으로 해결이 안 되면, 스크린샷과 함께 하나하나 따라할 수 있는 가이드가 있어요!

📘 Reedo(리도)님의 윈도우 전용 상세 가이드 — 보안 설정까지 윈도우 전용 5단계 가이드

Chapter 1-1 대안 · 윈도우만

🪟 WSL 없이, 파워셸에서 바로 설치하기

앞 슬라이드의 WSL2가 잘 안 되거나 부담스러우면 이 방법만 해도 돼요.
윈도우에 원래 들어있는 파워셸에서 명령어 한 줄이면 끝나요.

🍎 맥 사용자는 이 페이지 스킵! → "다음" 버튼 누르세요

둘 중 하나만 하면 돼요. WSL2(앞 슬라이드)와 파워셸(이 슬라이드)은 양자택일이에요.
WSL2 = 윈도우 안에 리눅스를 깔아서 맥과 똑같이 쓰는 방식 · 파워셸 = 윈도우에서 그대로 쓰는 방식
1 파워셸 열기 (관리자 권한 필요 없어요)

키보드에서 Windows 키 → "PowerShell" 검색 → 그냥 클릭

💡 파워셸은 윈도우에 기본으로 들어있어요. 따로 설치할 필요 없어요. (PowerShell 5 이상이면 OK)

💡 파워셸에서 붙여넣기는 마우스 오른쪽 클릭이에요. Ctrl+V가 아니에요!

2 설치 명령어 한 줄 실행
파워셸 iwr -useb https://openclaw.ai/install.ps1 | iex

공식 윈도우 설치 스크립트예요. Node.js가 없으면 알아서 같이 깔아줘요.

winget → Chocolatey → Scoop 순서로 시도하고, 셋 다 없으면 공식 Node 24를 통째로 내려받아 PATH에 넣어줘요. 그래서 Node를 미리 안 깔아도 돼요.

3 파워셸 창을 닫고 새로 열기

설치 직후엔 openclaw 를 못 찾는 게 정상이에요. PATH가 새 창부터 적용되거든요.

4 설치 확인
파워셸 (새 창) openclaw --version
OpenClaw 2026.7.1-2 (0790d9f) ← 성공! 🎉
※ 뒤 숫자·괄호 안 글자는 설치 시점마다 달라요. 이름이 나오면 성공!
✅ 여기까지 됐으면 Chapter 1-2(Node.js)와 Chapter 2(오픈클로 설치)는 건너뛰어도 돼요.
바로 Chapter 3 — 온보딩으로 가시면 됩니다!
🔧 여기서 막히는 경우 (클릭하면 열려요)
❌ "이 시스템에서 스크립트를 실행할 수 없으므로" (실행 정책 오류)

파워셸이 외부 스크립트를 막고 있는 거예요.

→ 해결법: 이 창에서만 잠깐 허용하고 다시 실행하세요.

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

현재 창에만 적용돼서 안전해요. 창을 닫으면 원래대로 돌아가요.

❌ "openclaw: 용어를 인식할 수 없습니다" (설치는 됐는데)

→ 해결법: 파워셸 창을 완전히 닫고 새로 열어보세요. 제일 흔한 케이스예요.

그래도 안 되면 Node가 제대로 깔렸는지 먼저 확인:

node --version # 22.22.3+ 또는 24.15+ 여야 해요
❌ Node 23이 깔려 있어요

오픈클로는 Node 23을 지원하지 않아요.

→ 해결법: 24 LTS로 바꿔주세요.

winget install OpenJS.NodeJS.LTS
❓ Git도 미리 깔아야 하나요?

아니요, 필요 없어요. 기본 설치는 npm 방식이라 Git 없이 돌아가요.

개발자용 git 설치 방식(-InstallMethod git)을 고를 때만 필요하고, 그마저도 없으면 스크립트가 알아서 챙겨줘요.

WSL이 안 깔려서 헤맸다면 이쪽이 훨씬 편해요 🐾

Node 23은 지원하지 않아요. 공식 지원 범위는 22.22.3+ · 24.15+ · 25.9+ 예요. 짝수 버전(22 또는 24)을 고르면 안전해요.
✅ 별도 설치 필요 없어요!

Node.js가 없을 경우 자동으로 설치해줘요.

이미 Chapter 1-1을 완료했다면 → 바로 Chapter 3 (온보딩)으로!

Cmd + Space → "터미널" 또는 "Terminal" 입력 → Enter
2 Homebrew맥에서 프로그램을 쉽게 깔아주는 도우미예요. 앱스토어처럼 "이거 깔아줘!" 하면 알아서 깔아줘요. 근데 마우스 대신 글자로!로 설치 (권장)

Homebrew가 없는 경우, 먼저 이걸 복사해서 터미널에 붙여넣기:

터미널 /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

비밀번호를 물어보면 맥 로그인 비밀번호를 입력하세요. (화면에 안 보이는 게 정상!)

Homebrew 설치 후 (또는 이미 있는 경우):

터미널 brew install node

터미널 node --version

❌ "brew: command not found"

Homebrew 설치가 안 된 거예요.

→ 해결법:

위의 Homebrew 설치 명령어를 먼저 실행하세요. 설치 후 터미널을 껐다 다시 열어야 인식돼요!

Apple Silicon 맥(M1/M2/M3/M4)이면 추가로 이것도 실행:

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

Xcode 명령줄 도구가 필요해요.

xcode-select --install
❌ "node: command not found" (설치했는데 안 됨)

→ 해결법: 터미널을 완전히 껐다가 다시 열어보세요.

그래도 안 되면 nodejs.org에서 .pkg 파일을 직접 다운받아 설치해도 돼요.

Homebrew 없이도 nodejs.org에서 직접 .pkg 파일을 다운받아 설치할 수 있어요!

🥇 1순위 추천

Anthropic → Claude CLI

Claude Max/Pro 구독자라면 이거! Provider에서 Anthropic을 고른 다음, 인증 방식에서 Claude CLI를 선택하세요.

  • 인증: 토큰 자동 공유 (이미 claude로 로그인돼있으면 끝)
  • 비용: 구독 한도 내에서 무료 (API 토큰 안 씀!)
  • 사전조건: Claude Code CLI 설치 + claude /login 완료

Anthropic → OAuth

Claude 모델을 OAuth로. 구독자 아닌 분도 OK. Provider에서 Anthropic → 인증 방식에서 OAuth.

  • 인증: OAuth (브라우저 로그인만 하면 끝)
  • 비용: Anthropic API 사용량 기준
  • 모델: Claude Sonnet/Opus 자동 설정

OpenAI

GPT 모델 사용. Codex OAuth로 간편하게.

  • 인증: Codex OAuth 또는 API 키
  • 비용: OpenAI 구독/크레딧 기준
  • 모델: GPT-4o 등 자동 설정

기타 / 무료 옵션

Ollama(로컬), Chutes(무료 크레딧), OpenRouter, Google, xAI, Mistral 등.

  • 대부분 API 키 붙여넣기 방식
  • Ollama는 로컬 실행 — 인증 불필요

Chapter 4-3

슬랙에 데려오기 💬

팀이 같이 쓰는 자리에 봇을 앉혀요

왜 슬랙까지 하냐면 — 텔레그램은 나 혼자 쓰는 자리예요. 슬랙은 사람도 봇도 같은 채널에서 같이 일하는 곳이라, 동료가 "그거 어떻게 했어?" 할 때 화면을 캡처해 보낼 필요가 없어져요.
⚠️ 회사 슬랙은 오늘 쓰지 마세요

봇을 붙이려면 앱 설치 권한이 필요한데, 회사 슬랙은 대부분 관리자 승인이 필요해서 오늘 안에 안 끝나요.

→ slack.com/get-started 에서 개인 워크스페이스를 무료로 하나 만들어주세요. 3분이면 돼요. 회사 슬랙은 오늘 익힌 다음에 붙이면 됩니다.

1 슬랙 앱 만들기 — 매니페스트 한 덩이로

📝 붙여넣기 전에 두 군데만 바꿔주세요
"name" → 한글 이름 (예: 뽀야, 구름이)
"display_name" → 영문 아이디 (예: bboya, gureum)

2 슬랙에서 부를 이름 한글로 바꾸기

매니페스트엔 영문 아이디를 넣었으니, 슬랙에서 @뽀야 처럼 한글로 부르려면 한 번 더 손봐야 해요.

왼쪽 메뉴 App Home → Your App's Presence in Slack → Edit → Display Name (Bot Name) 을 한글로 → Save

3 열쇠 ① 앱 토큰 xapp-

Socket Mode는 켜졌지만 앱 토큰은 자동으로 안 만들어져요. 직접 발급해요.

왼쪽 메뉴 Basic Information → 아래로 스크롤 → App-Level Tokens → Generate Token and Scopes

이름은 아무거나(bboya) → Add permission by Scope 에서 connections:write 하나만 선택 → Generate

드롭다운에 scope가 3개 뜨는데 connections:write 하나면 충분해요. 나머지 둘은 여러 워크스페이스에 배포하는 앱용이라 우리한텐 불필요해요.
⚠️ 이 토큰은 창을 닫으면 다시 못 봐요

→ 나오자마자 메모장에 붙여넣어 두세요. xapp- 으로 시작해요.

4 열쇠 ② 봇 토큰 xoxb-

왼쪽 메뉴 Install App → Install to Workspace → 권한 허용

Bot User OAuth Token 이 나와요 → 이것도 메모장에! xoxb- 로 시작해요.

🔑 이제 토큰이 두 개 모였어요
xapp- 앱 토큰 (3단계)  /  xoxb- 봇 토큰 (4단계)
⚠️ 둘을 바꿔 넣는 게 제일 흔한 사고예요. 에러도 안 뜨고 그냥 조용히 대답을 안 해요. 앞 글자로 구분하세요.
⚠️ 토큰은 비밀번호와 같아요. 채팅방이나 카톡에 붙여넣지 마세요.
5 오픈클로에 연결 — 명령어 한 줄

텔레그램 때와 똑같아요. 토큰 두 개를 그대로 넣어주면 끝나요.

Ubuntu 터미널 / 맥 터미널 / 파워셸 openclaw channels add --channel slack --bot-token xoxb-로_시작하는_봇토큰 --app-token xapp-로_시작하는_앱토큰
두 토큰의 자리를 바꿔 넣는 게 제일 흔한 사고예요.
--bot-token 에는 xoxb-, --app-token 에는 xapp-. 바꿔 넣으면 에러도 없이 그냥 조용히 대답을 안 해요. 앞 글자로 꼭 확인하세요.
